## ✨ Features & Architecture

* **🍱 Interactive Bento Grid Layout:** High-density, modular visual organization showcasing education, technical skills, production applications, and milestones.
* **✨ 3D Tilt & Cursor Spotlight:** Smooth GPU-accelerated mouse tracking providing dynamic 3D perspective shifts and radial spotlight highlights.
* **🌌 Dynamic Canvas Particle Network:** Interactive background canvas rendering animated floating nodes and dynamic distance-based connecting vectors that adapt to dark and light modes.
* **🌓 Dual Theme Engine:** Instant transition between dark mode and crisp light mode with persistent user preference storage via `localStorage`.
* **📄 ATS-Optimized Single-Page PDF Generation:** Integrated Node.js compiler (`generate_resume_pdf.js`) using `pdfkit` that produces a vector-sharp, 1-page ATS-compliant PDF with embedded hyperlinks.

## 🚀 Running Locally

Clone the repository and launch directly:

```bash
git clone https://github.com/Hrishi9o/Resume.git
cd Resume
```

Simply open `index.html` in any modern web browser or use a live server:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js / npx
npx serve .
```

---

## 📄 Re-Generating the Resume PDF

To compile or customize [`Hrishi.pdf`](./Hrishi.pdf), run the PDFKit generator script:

```bash
npm install
node generate_resume_pdf.js
```

This generates a 1-page ATS-compliant vector PDF with verified clickable annotations and balanced margins.
